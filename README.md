# HOLODYLNYK — що приготувати з того, що є

Локальний кулінарний застосунок українською. Введи продукти з холодильника —
отримай рецепти з % збігу, таймером, режимом готування і списком покупок.

88 рецептів, git-історія по комітах (дивись `git log --oneline`).

## Запуск

```sh
cd holodylnyk
python3 -m http.server 8000
# відкрити http://localhost:8000
```

Жодного білда: чистий HTML + CSS + JS. Офлайн після першого відкриття
(service worker `sw.js`).

## Можливості

- 88 рецептів з фото, часом, ккал, складністю, дієтами
- Толерантний пошук: стемінг відмінків, без ь/ъ, багато слів через І
- Пошук за продуктами, підказки, голосовий ввід (uk-UA), поле «Не хочу»
- Швидкі чіпси, сортування (збіг / докупити / час / ккал), лічильник категорій
- Улюблене, рейтинги ★, «я приготував» з конфеті, «Моя кухня» зі стріком
- Модалка: порції-калькулятор, кроки з прогресом, авто-таймери з тексту,
  шаринг, копіювання, друк, порада шефа, клік по ○ додає продукт
- Список покупок з кількостями × порції
- Режим готування на весь екран (стрілки ← →), фокус-пастка Tab
- Меню на тиждень з сумарним списком покупок
- Світла/темна тема, PWA, JSON-LD, діплінки `#r-id` з живим title
- Кнопка «перевірка даних» у футері — самоперевірка рецептів

## Структура

```
index.html  — розмітка
css/style.css — тема, адаптив, друк
js/recipes.js — дані (window.RECIPES, window.POPULAR)
js/app.js     — логіка
sw.js, manifest.webmanifest, icon.svg — PWA
```

## Дані

Сховища localStorage з префіксом `hol_`: ings, excl, favs, shop, recent,
cooked, rate, theme, filters.
